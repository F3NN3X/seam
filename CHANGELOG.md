# Changelog

All notable changes to Seam. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/). A release takes the section headed with its version as its notes, so move **Unreleased** under a new `## [X.Y.Z] - YYYY-MM-DD` heading before tagging.

## [Unreleased]

### Added

- **Copy workspaces to a new desk.** A desk with no workspaces yet shows a note on Workspaces when another desk has some and the same number of screens, with **Copy workspaces from** (a menu when several desks qualify). Each screen's apps go to the screen in the same place: the same monitor first, then main to main, then left to right (top to bottom when stacked), by physical position when both desks are lined up. Everything in a workspace is kept, as raw settings; the workspace in use, the default and the sign-in choice stay behind. A notification offers Undo for 8 seconds. New `workspace.copy_from_desk` method (the Seam window only), and `desks.list` gains `workspaces`. A desk now remembers its screens (`screens` on it) each time it is connected.
- **Offer to restore after screens change.** Off by default, on Workspaces under **All workspaces**. After screens are plugged in or out or the PC wakes, once they've settled and **Keep windows in their zones** has run, a notice asks "Restore «Name»?" when a window of the workspace in use isn't in place. Clicking it is Snap back with other windows left alone. A re-fit now waits while a switch runs.
- **Folders, web links, terminals and editor folders.** **Add an app** has a third tab, **Other**, with four things a switch can start: a **Folder** in Explorer, **Web links** (1 to 20 http or https addresses as tabs of one new window of Chrome, Edge, Brave, Vivaldi, Opera, Helium or Firefox), a **Terminal** (Windows Terminal with 1 to 8 tabs, each with a profile from its own settings, a starting folder and an optional startup command) and an **Editor folder** (VS Code, Cursor, VSCodium, Windsurf, Zed or another editor Seam finds). Each is a row like any app, with a screen, a place and a start order; a switch binds the window it starts to the row, so it takes that window and no other, whatever **Remember folders and pages** says, and starts it again once it's closed. Snap back never starts one. **Change what it opens** on the row opens the same dialog. Export and import keep a folder, web links or an editor folder if it passes its check again. `item` on a row is new (see docs/api.md), `workspace.switched` has two new reasons, `item refused` and `startup command not from this PC`, and `config.get` and `workspace.get` show other clients only the item's `kind`.
- **Security: startup commands.** A Terminal tab can run a command you type, the one way a workspace runs a command. It runs only when a switch starts that terminal, never in a window that's already open, and only in PowerShell and Command Prompt tabs (a PowerShell command goes as an encoded command, a Command Prompt command can't have quotes). It's stored encrypted for your Windows account in `config.json` (`command_sealed`), so a command from another PC, another account, an import, a synced file or typed into the file by hand doesn't open and never runs: the tab opens without it and the row says so. Exports leave it out, imports drop it, and no other app or assistant can read, set or run it through the API or MCP (a switch another app asks for, Snap back and Switch back included, opens the terminal without it, and `skipped` says `startup command not run for another app`).
- **Review a capture before it saves.** **Capture current windows** lists the windows it is about to save, grouped by screen, with the likely noise already unticked: apps that run as administrator, a short list of apps usually open only for a moment (Settings, Task Manager, installers, the snipping tools) and a second window with the same app and title. Untick any other, name the workspace and save: the workspace holds only the ticked windows, as they were when the list opened. A list left open for 2 minutes says "Capture again". New `workspace.capture_preview` method, and `workspace.capture` takes `token`, `take` and `closed` to save one (the Seam window only). The capture shortcut, **Save windows to the active workspace**, and the first-run setup still save everything at once.
- **Turn off an app that isn't open.** When some of a workspace's windows aren't open, **Update from screen** lists them, each with its app, screen and the window's title, and asks, for each, **Keep**, **Turn off** or **Remove**, then offers Undo for 8 seconds, which puts back removed and turned-off rows alike. With every app closed it asks nothing and changes nothing.
- **Drag the workspace list into order.** Each item has a grip on hover and focus, Alt+Up and Alt+Down move it, and a notification offers Undo for 8 seconds. The order is the numbering: **Add window to workspace 1** to **9**, `workspace.add_window` with a `number` and the tray's Workspace items follow it. A new `workspace.move` method (the Seam window only) does the move, and the workspaces are moved as saved, so no key is lost.
- **Turn off this app.** A row's **...** menu keeps the row but takes it out of switches, Put windows back, **Open alongside**, auto-apply and the sign-in workspace. It uses the new optional `off` on a row, left out of the file while it is false. **Update from screen** and **Add window to workspace** keep it. `workspace.get` and `workspace.edit_row` have `off` (an assistant may only turn a row off), and `workspace.status` gives the state `off`.
- **Windows already open.** Each workspace chooses **Move back** or **Leave where they are** for the windows already open when you switch. **Put windows back** always moves them. It uses the new optional `open_windows` on a workspace, left out of the file while it is `move`.
- **A switch says when a screen isn't connected.** An app whose saved screen isn't connected stays where it is, and the switch reports `screen not connected` in `skipped`, and says so in its notice.
- **A switch says which app didn't work, and why.** After a switch that couldn't start or move an app, one notice says "Switched to Work. 2 apps had a problem" with the first two ("Slack isn't installed, or Seam can't find it"), and clicking it opens Workspaces on that workspace. From the Seam window it is the window's own notice, with Undo. Nothing shows when everything worked. The workspace's page keeps the result in memory until its next switch: a note with **Switch again**, and the reason on each affected row. `workspace.switched` entries in `skipped` gain `row` and `why`, and the event gains `problems` and `cancelled`. New `workspace.last_switch` method and `workspace.switching` event.
- **Stop a switch that is starting apps.** Press Esc, or click the "Switching to Work" notice that shows after 2 seconds (the Seam window's has **Cancel switch**). The switch starts no more apps and stops waiting for the ones it started, windows already placed stay, and **Other windows** isn't applied. Esc is watched only while a switch starts apps, isn't swallowed, and isn't watched while Seam steps aside for a game. New `workspace.cancel` method, open to assistants, and `seam_cancel_switch` tool; `workspace.switched` has `cancelled`.
- **Inactive screens on Displays.** A screen that is connected but turned off in Windows shows as "Inactive", with **Open Display settings**. `state.get` lists them as `screens_inactive`. Information only.
- **Close this workspace and Minimize this workspace.** On a workspace's **...** menu, in the tray menu after **Put windows back**, and as two shortcuts with no key set. They take the windows the workspace's rows match, never a pinned window, one kept out of switches, one running as administrator, an app under **Left alone**, or a row that is off. **Close this workspace** lists the windows first (untick one to keep it) and sends each a normal close request, so an app with unsaved work asks you first; Seam never ends a process. **Minimize this workspace** offers Undo for 8 seconds. New API methods `workspace.windows`, `workspace.close`, `workspace.minimize` and `workspace.minimize_undo`, and events `workspace.closed` and `workspace.minimized`. Assistants get none of them, and no MCP tool was added.

Config: `screens` on a desk (each screen's device path, number, name, Windows rectangle, whether it is the main screen and, once lined up, its place in mm) and `workspaces_offer_restore` are new and optional, left out of the file while empty or off. An older Seam ignores them, and if it saves it drops them: the desk just isn't offered as a copy source until it's connected again, and the restore offer turns off. Nothing else new for the two before them, the results live in memory. `off` on a workspace row and `open_windows` on a workspace are new and optional. An older Seam ignores them, and if it edits that workspace it drops them, so the row is on again and the workspace moves open windows, as before. `item` on a workspace row is new and optional (a folder, web links, a terminal or an editor folder, with a Terminal tab's `command_sealed`). An older Seam ignores it, and if it edits that workspace it drops it, so the row starts its app with nothing, which is safe. `close_workspace` and `minimize_workspace` in `hotkeys` are new and optional, null until set. An older Seam ignores them.

### Changed

- **Update from screen removes apps that aren't open** is now **Apps that aren't open** on All workspaces, a choice of **Keep**, **Turn off** and **Remove** that sets what each app starts at in the list. `workspace.capture` with `into` and no `token` applies it to the apps that aren't open. The Seam window offers the only Undo for its own updates; the tray's balloon stays for the tray's.

Config: `workspaces_update_closed` (`keep`, `turn_off` or `remove`) is new and optional, left out of the file until it is set. Without it Seam reads `workspaces_update_removes_closed` as before (true is Remove, false is Keep), and writing the choice writes that flag too, true only for Remove, so an older Seam does the closest thing (Turn off reads as Keep there). Nothing is removed from the format.

## [0.8.0] - 2026-11-16

### Added

- **A redesigned Seam window.** It has Mica, Windows 11's translucent backdrop, when Transparency effects is on and no contrast theme is, and draws its own title bar with Back, the command bar and the window buttons, which keep Snap Layouts. The sidebar's status card opens its page and reads "Remap on", "Remap paused" or "New screen to line up". Colours, sizes and type follow one set of design tokens, so muted text and the Off switch are easier to see, and Seam's own controls draw a 2 px focus ring outside the control. Every page title has a **?** that opens its Help topic, and pressed and disabled controls look different from rest, and say why when disabled.
- **A Windows page.** Smart tiling (still per screen), **Put windows back when Seam quits**, the focus and pin borders, pinned windows, **Move and resize from anywhere**, the overview corner, other window managers, **Where apps open** with **Left alone**, and **Step aside for games and full-screen apps** move there from Zones, General and the app rules page. Every setting and its config key are as before. The borders are lists with a dot per colour, **Move and resize from anywhere** has Off, Alt, Win and Ctrl+Alt, and **Open the overview from a corner** has Off and the four corners, keeping the corner you picked while it's off. `seam-settings.exe --page windows` opens it.
- **A command bar.** The search field is now in the title bar, and Ctrl+F focuses it. Results come in two groups, Actions (Switch to a workspace, Put windows back, Capture current windows, Line up screens, Pause pointer remap, Pause Seam, Show changed settings, Copy diagnostics) and Settings, with the keys shown for set shortcuts. **Show changed settings** filters a page to the settings that differ from their default, and says "Nothing on this page differs from its default" when none do.
- **One Undo notice with a countdown.** Every Undo shows in one notice at the bottom right with an 8 second bar, one at a time. Update from screen, a workspace switch away from another workspace, Use suggested keys, Reset to default, Duplicate and the existing deletes and edits offer it. Put windows back shows a plain notice, and Import keeps its question and has no Undo.
- **A new screen is called out.** When a set of screens Seam hasn't seen is connected and Seam would ask to line them up, Displays says so with **Line up the new screen**, and the sidebar reads "New screen to line up".
- **Tray icon states.** The icon shows on, paused (the quiet mark with a slash) or needs you (a red dot, for a new set of screens, until the balloon has shown). Its tooltip says the state in words.
- **First-run setup.** A new install shows a three-step dialog the first time the window opens: line up your screens, pick zone layouts, capture a workspace. **Skip setup**, **Do it later**, Esc or a click outside ends it. It uses the new `setup_done` config field, `false` on a new install. A config without the field counts as `true`, and gets the field written back the next time it is saved, so no one who already uses Seam sees it.
- **Keyboard, text size and contrast themes in the Seam window.** F6 and Shift+F6 move between the title bar, the sidebar and the page, Up and Down work in the sidebar, the workspace list, Help topics, border rows and the app picker, the mouse's back button goes back, and the workspace list, the map's screens and the app picker rows work with Tab, Space and Enter. Windows' Text size scales the window's text. A contrast theme gives it system colours with solid outlines and no Mica. Narrator reads the map's borders and screens, and the sliders' values. Known gaps: the command bar's highlighted result isn't read as you type, colour entries with a dot have no name, and Undo notices and dialog titles aren't announced.
- **Shortcuts: In use, All and Use suggested keys.** The page opens on the shortcuts that have keys, **All** adds the rest folded under "Not set yet", and a filter finds one by name or keys. A clash with another Seam shortcut or a key Windows keeps is saved, as before, and shows in red with the reason. **Use suggested keys** fills only shortcuts with no keys, never with a clash, and Undo clears only those still holding them.
- **Help topics open in place.** The Help page starts with Getting started, lists topics by page, and opens one with a trail, **Go to setting** and a Related list. Back in the title bar and Alt+Left return to the list. The topic text is as in 0.7.0.
- **Displays: a desk menu and a clickable map.** The desk menu under the title lists the saved desks, with **Rename this desk** and **Forget desks not seen in 30 days**, which names the desks and offers Undo. Clicking a border on the map selects it, and the borders fold into one line that opens by itself when one needs lining up. A legend sits under the map. The rarer pointer options are behind **More pointer options**.
- **Zones: tiles in one row, and a shorter snapping section.** The built-in tiles, your layouts and **New layout** sit in one row, the preview is at most 480 px wide, deleting a layout no screen uses just deletes it with Undo, and **Reset to default** on Snapping puts the options back (screen margins stay). **Pause** is now one of the snapping key's choices. A config with both a key and **Pause to snap** keeps both. Screen margins open a popover with four sliders.
- **Workspaces: grouped by screen.** Apps are grouped by the screen they go on, and several windows of one app share a row. **Start if it's closed** is in the row's **...** menu, **Shortcut** is a row on each workspace, and **Capture current windows** is a secondary button. Undo replaces the question wherever an action can be undone.
- **Open time is logged.** With `--log` or `SEAM_LOG=1`, the Seam window writes how long it took to open ("app running", "Panel::new", "first frame").

- **Scrolling, a fifth smart tiling family.** On Zones, **How windows are arranged** has **Scrolling** (`tiling.set` with `family: "scrolling"`): each new window is a column on a strip that can be wider than the screen, half the screen wide, after the focused one. The screen shows whole columns; the others wait outside every screen, never on the screen next to it, and still show in Alt+Tab, the taskbar and the overview, and going to one scrolls it into view. New shortcuts, no keys by default: **Scroll left** and **Scroll right** (also `tiling.scroll`), **Move column left**, **Move column right** and **Column width** (a third, a half, two thirds, full). Win+wheel over a Scrolling screen scrolls it a column at a time. Waiting windows come back onto their screen when Seam pauses, steps aside, has zones off or quits, and when Scrolling turns off. An older Seam reads the setting as Smart.
- **Open the overview from a corner.** "Open the overview when the pointer rests in a corner" on Zones, off by default, with the corner to use: top left, top right, bottom left or bottom right of the whole desk, never a corner between two screens. Resting the pointer there for 400 ms with no button down opens the overview, once per visit, but not during a drag, while Seam is paused or steps aside, or with a full-screen app in front. `windows.corner_overview` in the config.
- **Add window to workspace 1 to 9.** Nine shortcuts on Shortcuts (no keys by default, or `workspace.add_window` with `id` or `number`) add the focused window to that workspace, numbered in the list's order. A new row gets the window's place with **Launch** off; a window that already has a row there updates that row instead of adding another. It never removes the window from another workspace, and a notification offers Undo for 8 seconds. Seam's own windows, apps under **Left alone**, administrator apps, windows kept out of workspace switches and windows with no taskbar button are refused with the reason. Assistants can't use it.
- **Put windows back when Seam quits**, a switch under smart tiling on Zones, off by default. With it on, Quit Seam frees every tiled screen on every virtual desktop first, as Free all windows does, and waits up to a second for the windows to move. An update, a restart, a crash and a sign-out keep the arrangement, as for pins. `zones.tiling_free_on_quit` in the config.
- **Screen margins.** On Zones, next to the gap, each screen gets a top, right, bottom and left margin in pixels at 100% scale (0 by default, at most a quarter of the screen per side). Zones and their drag overlay, Tile and Fit group, Quick layout, smart tiling, snap beside, the overview's drop targets, Rotate, Reset sizes and Keep windows in their zones work inside what is left. Maximized and full-screen windows, Line Up, and workspaces' saved places are unchanged. `desks.<sig>.margins.<device path>` in the config, set with `config.patch`.
- **Desktop jumps in the overview.** Ctrl+Tab and Page Down go to the first window of the next virtual desktop's group, Ctrl+Shift+Tab and Page Up to the previous one, wrapping around, and the wheel over a group's label does the same. With a search typed, groups with no match are skipped.
- **Rotate windows and Reset sizes.** **Rotate windows** (no key by default, or `screen.rotate`) moves every window snapped on the screen under the pointer to the next zone, the last to the first, and the same key with Shift added goes the other way. A stack goes as one, and floating, pinned, sticky, minimized and administrator windows stay where they are. A tiled screen rotates its tiles. **Reset sizes** (no key by default, or `screen.reset_sizes`) puts a screen whose layout shows Changed back to the layout it came from, with its windows, and evens out a tiled screen's splits. Both offer Undo for 8 seconds. The Stream Deck plugin, now 0.8.4, has a Rotate windows key.
- **Overview.** **Show overview** (no key by default, also in the tray menu, and `overview.show`) fills every screen with its windows, live previews or app icons, grouped by virtual desktop. Type to search by title or app, arrows and Enter go to a window, also on another desktop, and dragging one onto a zone or another screen moves it there. Esc closes it.
- **Smart tiling.** "Arrange new windows automatically" on Zones tiles each new window on that screen, on the virtual desktop you are on, off by default: Smart splits the largest window's space, or Columns, Main + stack and Grid share it evenly. Closing or minimizing closes the gap, a window too big for its share stacks, and dialogs, rule-placed apps and windows you move by hand float and are never moved back. **Float or tile this window** and **Free all windows** (no key by default, Free all also in the tray), `tiling.set`, `tiling.free` and `tiling` in the state, and "Leave out of smart tiling" per app on Where apps open.
- **Stacks.** Several windows can share one zone, one on top. S during a drag stacks the window on the one in the zone instead of swapping, with Undo, and a slim mark at the bottom of the zone shows how many it holds. **Next window in stack** and **Previous window in stack** (no key by default), `window.stack`, `window.stack_cycle`, `stacks` in the state, and a Cycle stack key in the Stream Deck plugin 0.8.3. The others stay behind the top one in the zone, so Alt+Tab and the taskbar still reach them. Workspaces keep stacks, and a restart finds them again.
- **Assistants (MCP).** `seam-mcp.exe` lets an AI assistant such as Claude read Seam's status, switch workspaces (never closing windows), Snap back and Switch back. **Let assistants use Seam (MCP)** on General turns it on, and it is off by default. **Let assistants change workspaces**, also off by default, adds Quick save, renaming, creating, editing a row's place or how it shows, removing a row and Show every window, each with an Undo notice, and never a program, a shortcut or a launch turned on. General shows whether an assistant is connected and the path to copy. The zip and the installer include `seam-mcp.exe`.
- **Show every window**, a switch on each workspace, off by default. A window saved minimized comes back onto its place, or maximized, and counts as moved while it's minimized, so Snap back and auto-apply restore it.
- **Open with**, under an app's name in a workspace, makes a switch that starts the app open a path or link I typed: a full path on a local drive as the app's one argument, or an http, https, obsidian, vscode, vscode-insiders or spotify link through the shell. Anything else is refused and shows under the app, and so is a path for a program that would run it. It is never captured or exported, import drops it, and only the Seam window sees it.

### Fixed

- **Free all windows offers Undo** for 8 seconds: tiling turns on again on that screen and desktop, and the windows you haven't moved since take their places back.
- **Smart tiling leftovers.** A window a slow app minimizes just after a workspace switch gives its space up too. A tiled window saved in a workspace is tiled again when restored after minimizing. After Win+D, Seam no longer wakes every 600 ms while every window stays minimized. Undo of a split on a tiled screen puts its splits back at once. A deleted virtual desktop's arrangement ends, and its setting stays.
- **Scrolling leftovers.** A slow app can no longer hold Quit past its one second. Windows brought back on a display change move in one step at the new screen's scale. A strip holds up to 32 columns, and a window that opens or is dropped past that floats.
- **Undo of Tile or a layout pick maximizes again** the windows that were maximized before. Undo of a split does too.
- **"When I sign in" with Do nothing on every desk** no longer starts the sign-in timer. Changing a desk's choice later in that start starts it.
- **A pin the window manager refuses** is no longer tried again on every pass over the open windows. A window gets one more try when it is shown again, then I leave it alone, with one line in the log.
- **Alt+drag at quit** keeps its hook until you let go of the button, for at most 2 seconds, so the release doesn't reach the app.
- **Stream Deck plugin 0.8.2:** the Apply layout key asks Seam for a screen's layouts once, not on every redraw.
- **The log says when Ease cursor movement is missing** from the registry on a Windows that has the setting, and that Seam reads it as on.
- A window in a snap-beside group now leaves it as soon as I drag it away, not a moment after. Closing or minimizing a window in a group is now noticed however many windows the groups hold, where only the first 128 were.
- **Keys during a drag** no longer slip through to the app when a drag starts right after the last one, and a key held past the drop no longer repeats into it. Esc during a divider handle's drag no longer reaches the focused app as well.
- **Alt as the show key, or the Alt+drag key,** now lets Alt+Tab through to Windows, and the wheel and 1, 2, 3, 0 steer while it is held. With Win as the Alt+drag key, Win with the wheel, Tab and 1, 2, 3, 0 steers during that drag instead of reaching Windows.
- Snipping Tool's capture overlay, the lock screen and the Xbox Game Bar no longer make Seam step aside for a moment. A Direct3D game on another screen no longer makes it step aside for a maximized app with an auto-hidden taskbar.
- **A split or pull-out made while Seam was busy** is saved after all, with its Undo, instead of being dropped and leaving the saved layout old.
- **Windows Seam only knows by their zone mark** (after a restart) are renumbered with the others on a split or pull-out, and Undo gives their numbers back.
- **A zone swap** leaves a window alone that I moved by hand before its turn came, and says so in the log.
- **A workspace row no longer keeps a window that isn't its own** when Windows reuses a window handle for another program's window.
- **Alt+drag** forgets an app's verdict the moment the app exits, so a new program that gets its process id isn't judged by it.
- **The overview tells a screen reader what is selected.** Narrator reads "Seam overview: app - title" as the selection moves, and how many windows are shown when none is selected.
- **The overview makes its fonts once and keeps them,** and while the app names and icons fill in, only the tiles that changed are put on screen again.
- **A second request to open the overview while it is still opening is dropped** instead of waiting up to 200 ms for the first, so Seam's tray no longer waits on it and two overviews can't start.

### Changed

- **Where some settings are.** Window settings that were on Zones, General and the app rules page are on the new Windows page, and **Show every window** reads **Bring back minimized windows**. The menu in the tray follows a fixed order: status lines, the workspaces with **Put windows back** (new), then Line up screens, the two pause items and Overview, then Open Seam and Quit Seam. Every item it had is still there. The tray's Pause and remap items show their shortcuts beside them.
- **Dates follow your Windows region** in the desk menu, the Displays border dates and About's release date, and fall back to a day and month if Windows gives none.
- **The Seam window redraws only when something changed.** A state update that changes neither the state nor the config no longer redraws it, and the Workspaces status redraws only when it differs.
- **The updater also updates `seam-mcp.exe`,** checked against the same signed manifest as the other exes. It's listed where updaters from 0.5.0 to 0.7.0 don't look, so they still update to this release, and `seam-mcp.exe` comes with the next update after that, or from the zip. A running `seam-mcp.exe` no longer blocks an update, and the installer stops it before it copies the new one; the assistant starts it again on its next use.
- With the debug log on, each step aside and return says what decided it: the window's class and exe, its rect against its screen and Windows' full-screen state. The zone swap's look at the open windows now starts when a drag does, so it is ready when zones show.

## [0.7.0] - 2026-11-13

### Added

- **Pull a window out of its zone**: drag a snapped window off its zone and hold Ctrl as you let go where no zone shows. If it was alone in its zone, the layout loses that zone, the neighbouring zone takes the space, the windows there move to fill it, and the layout shows as **Changed** with a notice and Undo for 8 seconds. Without Ctrl the gap stays, as before. With **Move and resize from anywhere in a window** on and Ctrl+Alt as its key, Ctrl is held for the whole drag, so it does nothing there.
- **Move and resize from anywhere in a window** on Zones, off by default: hold Alt and drag anywhere in a window to move it, or right-drag to resize it from the nearest edge or corner, as WinScreen and AltSnap do. Win or Ctrl+Alt can be the key instead, for apps that use Alt+click. Holding the show key snaps it into zones, and snapped neighbours follow a resize. `windows.alt_drag` (`on`, `key`) in `config.json`.
- **Snap beside a window** on Zones, on by default: while zones show during a drag, point at the edge of another window and the drop puts the two side by side, half each, or 1/3 and 2/3 with the wheel or 1, 2 and 3. On a screen with zones it splits the zone that window holds, saves the layout as Custom and offers Undo for 8 seconds. On a screen with no zones the two become a group until Seam restarts: they resize together from the edge between them, the gap has a handle, a third window dropped beside one joins, and a window dragged away, minimized, maximized or closed leaves. The middle of a held zone still swaps. `zones.snap_beside` in `config.json`.
- **Fit group to screen** on Shortcuts (no key until you set one) and `window.fit` in the API: stretches the focused window's group over its screen, keeping shares and order, or gives a window in no group the whole work area, with Undo for 8 seconds.
- **When I sign in** on General replaces the restore switch with one choice for each desk: **Do nothing** (the default), **Offer my last session** (as before) or **Open a workspace**. With **Ask first** on, the default, Seam shows "Open <workspace>? Click to open" and switches on the click. With it off, it switches about 10 seconds after the taskbar is up. It only acts when Seam starts at sign-in, waits up to 3 minutes while a full-screen app is in front, and a pause by hand cancels it. It acts on the desk that is current when it fires. A deleted workspace, or one that isn't for the desk, opens nothing and the log says so. `sign_in` (`mode`, `workspace`, `ask`) on a desk through `config.patch`; `restore_session` on on becomes **Offer my last session** on every desk the first time Seam starts, and a desk seen later starts at **Do nothing**.
- **Stream Deck plugin 0.8.1** carries the Apply layout and Pause Seam keys and Open alongside. Each plugin change now raises its version, since Stream Deck only replaces an installed plugin with a newer one.
- **Keep on top** for an app rule, on the app's row under **...** on **Where apps open**, and **Keep out of workspace switches**: its windows are pinned the way a pin by hand is, with the pin border, **Release pinned windows**, the close notice and the API, when they open or when you make the rule while the app is open. Choose **Doesn't move** as its place to only pin an app. **Release pinned windows** frees them until the window is opened again, and the log says how many were pinned by rules. `pin` (`top`, `sticky` or `both`) on an entry of `app_rules`.
- Stream Deck: an **Apply layout** key (pick a screen and a layout; it lights while the screen has it), a **Pause Seam** key (lit while paused, "Full screen" while Seam waits for a full-screen app) and an **Open alongside** checkbox on the workspace key. `zones.apply` and `zones.layouts` in the API, and `layout` on each screen in the state.
- **Step aside for games and full-screen apps** on General, on by default: while a game, a full-screen video or a slide show is in front, Seam unregisters its shortcuts so the app gets those keys, shows no zones and hides the divider handles, and turns Spotlight and the focus border off. Everything comes back when you leave it. Seam finds it from Windows' own full-screen state (`SHQueryUserNotificationState`) and from a window that covers a whole screen, on each focus change, with no polling. `step_aside_fullscreen` in `config.json`.
- **Pause Seam**: a tray item (**Pause Seam** / **Resume Seam**), a shortcut (`hotkeys.pause_seam`, no key until you set one) and `seam.pause` in the API. It does all of the above, and also turns the pointer remap and edge resistance off (without changing your setting), stops app rules and auto-apply placing windows, and waits to check workspace drift. A pause isn't saved, so a restart resumes. `paused` and `stepped_aside` in the state, a grey tray icon and General say which.
- Dragging a window with zones showing previews the drop: the lit zone is where it lands, and grey outlines show where windows it swaps with go. While zones show, the **mouse wheel** steps through the whole zone, 1/2, 1/3, 2/3, the zone with its neighbour and the whole screen, with the share on the side nearest the pointer, and **right-click** drops it without a zone. The keys do the same: **Tab** steps through the zone, the zone with its neighbour and the whole screen (**Shift+Tab** back unless Shift shows zones), **1**/**2**/**3**/**0** give the window a half, a third, two thirds or all of it, the **arrows** pick the side, and **Esc** drops it without a zone. A part splits the zone, saves the layout as Custom and offers Undo for 8 seconds. Every other key and click reaches your apps. **Pause to snap** (`zones.pause_to_snap`) shows zones when you hold still, and **Show keys while dragging** (`zones.drag_hints`) lists the keys on the screen; both off by default.
- **Update from screen removes apps that aren't open** on Workspaces, off by default: with it on, Update from screen removes the rows of apps with no window open, instead of keeping them, and a notification offers Undo for 8 seconds, which puts them back where they were. Quick save, **Where it is now** and Capture never remove a row. `workspaces_update_removes_closed` in `config.json`; `workspace.capture` with `into` follows it.
- **Swap with the window already in a zone** on Zones, on by default: dropping a window on a zone another snapped window holds makes them trade places, instead of one lying on the other. If the dropped window was loose, the other takes its old spot and size, and a drop across several held zones sends those windows to its old zones in the same order. Off keeps the overlap. `zones.swap_on_drop` in `config.json`.
- Dragging the edge of a window in a zone moves the windows in the zones on the other side with it, live. No window goes below the smallest size its app allows: the next divider moves instead. When you let go, the window fits its zone, the layout is saved as Custom and every window stays snapped. Esc puts everything back. **Resize neighbours with a window** on Zones, on by default, and `zones.resize_neighbours` in `config.json`.
- Handles in the gap between snapped windows. Drag one to move that divider, with the windows on both sides following live, and the layout is saved as Custom. Right-click one to give a window 1/2, 1/3, 2/3, 1/4 or 3/4 of it and its neighbour, or to take a window out of its zones. **Handles between snapped windows** on Zones, on by default, and `zones.divider_handles` in `config.json`. **Size menu** on Shortcuts (no key until you set one) opens the same choices for the focused window, for a gap too narrow for handles. `window.share` and `window.ungroup` in the API.
- **Tile this screen's windows**: puts the loose windows on the screen under the pointer into its zones. A shortcut (no key until you set one), **Tile windows** in the tray menu (a submenu of screens when you have several), `screen.tile` in the API, and a **Tile screen** Stream Deck action. A screen with no layout is given one for the number of windows, and a notification offers Undo for 8 seconds.
- **Main + stack** and **Stack + main** layouts on the Zones page: a main zone of two thirds beside two stacked zones. An older Seam reads a screen with one of them as having no zones.
- **Where apps open**, a card on the Zones page: add an app, pick its screen and zone (or the full screen), and its windows go there once whenever they open, workspace or not. A workspace in use that has a row for the app wins. Dialogs, apps that run as administrator, apps under **Left alone** and windows that open during a switch are never moved, and a rule whose screen isn't connected does nothing. `app_rules` in the config holds them.
- **Grow window into its neighbour**, **Shrink window** and **Give window two thirds of its group** on Shortcuts, with no key until you set one. They move the dividers beside a window in a zone, and the windows in the other zones follow. No window goes below the smallest size its app allows: the divider beyond it moves instead. A second press of two thirds puts the zones back. The changed layout is saved as Custom. `window.resize` and `window.priority` in the API.
- **Switch back to the previous workspace**: a shortcut (no key until you set one), the first item of the tray's Workspaces menu, `workspace.switch_back` in the API, and a Stream Deck action. `previous_workspace` on a desk in `config.json`.
- **Open alongside**, on a workspace's **...** menu, switches once and leaves the other windows alone. `workspace.switch` takes `alongside`.

- **Focus on this window** minimizes the other windows on its screen, and pressing it again brings them back. A shortcut (no key until you set one), `window.focus_only` in the API (`scope` `workspace` minimizes everything outside the workspace in use), and a Stream Deck action.
- **Spotlight** dims everything but the window you're using. A shortcut (no key until you set one), `window.spotlight` in the API, `spotlight` in the state, and a Stream Deck key that shows whether it's on.
- A library of custom layouts on the Zones page, shared by every desk and screen: each has a tile after the templates, and a **...** menu with Edit, Rename, Duplicate and Delete. Editing one changes every screen that uses it, and deleting one leaves those screens with their zones. **New layout** starts one. `custom_layouts` in `config.json`, and `custom` on a screen's layout.
- **Quick layout**: a small panel on the screen under the pointer for picking its zone layout from the keyboard. Numbered thumbnails of the built-in layouts, the custom layouts made for that screen and None; 1 to 9 or the arrows and Enter pick, Ctrl+Z undoes the last pick, Esc or a click outside closes it. A shortcut (no key until you set one), `zones.quick` in the API, and a **Quick layout** Stream Deck action.
- **Save from windows** on the Zones page makes a library layout from where the windows on a screen are now, and snaps them into it. `zones.from_windows` in the API.
- Picking a layout on the Zones page puts the windows on that screen into the new zones, one window to a zone, snapped windows first. When windows moved, a notification offers Undo for 8 seconds.
- **Edge resistance** on Displays, off by default: the pointer waits at the edge to another screen until you push that many pixels past it, so you can grab a window's edge or corner at a screen border. It gives way while a mouse button is down, so window drags aren't slowed. `pointer.edge_resistance_px` in `config.json`, 0 to 100.
- Workspaces set each screen's zone layout. **Zones** in the workspace editor has a row per screen: **Keep as is**, **No zones**, a built-in layout or a library layout, with a thumbnail. A switch, Snap back and Open alongside set the layouts before placing the apps, and a last session restore doesn't. Capture, **Update from screen** and quick save record every screen's layout, and editing a library layout updates the workspaces that use it. A screen's layout that isn't the workspace's shows as moved, and **Put windows back** fixes it. Import maps the layouts to your screens and drops their links to the other machine's library. `zones` on a workspace in `config.json` and in `workspaces.list`.
- **Remember folders and pages** on Workspaces, off by default: a capture, and **Add an app** from the windows open now, also save the folder each Explorer window shows and the page each browser shows, and a switch takes the window the row was saved from or started, and once that's closed starts the app there in a new window. Other Explorer and browser windows are left alone, and an open window is never sent anywhere. Only folders on this PC's own drives and http or https pages are kept, and a page loses its whole query when any parameter's name contains a word like token, key, auth, code, sess or state. Private windows are skipped as best Seam can tell from the title. Workspace and settings Export leave them out, and both kinds of import drop them. **Forget saved folders and pages** removes them while the setting is off. `workspaces_remember_places` in `config.json`, and `place` on a workspace row.
- **Glued edge push** on Displays sets how far to push past a glued edge before the pointer crosses, 60 px by default and 0 to cross at once. `pointer.glue_push_px` in `config.json`, 0 to 200.

### Changed

- The Zones page shows the preview across the page, the built-in layouts in one row of smaller tiles under it, then **Your layouts**. A layout you make is for the screen you made it on, and **Used on...** in its **...** menu ties it to other screens or any screen. **Show all screens** lists every layout. `screens` on a `custom_layouts` entry, and one without it is for any screen.
- The **Custom** tile on the Zones page is gone. Clicking it only opened the editor for the screen's layout. **Edit layout** on a template now saves the result as a new library layout instead of changing the screen alone, and a screen whose layout is none of the tiles shows **Changed**, with **Save as layout**. Screens with a Custom layout from before show as Changed, and nothing is added to the library until you save one.

- **Never manage these apps** moved from General to the Zones page, where it is the **Left alone** list under **Where apps open**. It is still `zones.exclude`.
- When a window won't move because its app runs as administrator, the balloon names the app and tells it once per app instead of once per run. Clicking it opens Help, which has a new topic, "Apps running as administrator".

## [0.6.5] - 2026-11-09

### Added

- **Glue** in Line Up: screens that touch on your desk but have a gap between them in Windows can be glued with G, and the pointer crosses the gap where they physically meet. Line Up offers each such pair after the touching borders. A pair found from the screens' sizes starts glued, and a pair found only from the pixel layout starts off. Align arrangement keeps glued screens apart. Displays marks a glued border "Glued to the right edge of 1". `glued` on a border in `config.json` and in the state's `borders`.
- A glued edge holds the pointer until you push about 60 px past it, so an auto-hide taskbar on that edge still shows. Past the end of a glue, the edge is a dead edge that Seam holds.
- **Not on my desk**: press N in Line Up, or use the border's **...** menu on Displays (**On my desk** undoes it), for screens that touch in Windows but not on your desk. The pointer stops at that edge both ways, or crosses to a glued screen past it. Displays shows such a border as "Not on your desk". `not_on_desk` on a border in `config.json` and in the state's `borders`.
- Line Up names both screens with their model in each step, such as "Line up screen 3 (HDMI) with screen 4 (U3477)", and says which way to move each line, such as "straight below" or "level with".
- Line Up draws a band of faint diagonal stripes along the shared edge of the two screens, 10 mm apart on the desk, so you can see at a glance whether the edge runs straight across.
- **Type measurements in Line Up** on Displays, off by default. With it on, M in Line Up takes the offset between two screens as a number in cm and moves the lines to match. `lineup_measure` in `config.json`.
- **Two views of the layout** on Displays: **Seam** (your desk, with glued borders dashed and borders that aren't on your desk dotted) and **Windows** (the arrangement as Windows has it, in pixels, with "18 px gap" labels). The choice is remembered while the Seam window is open. `rect` on each of the state's `screens`.
- **Show on screens** on Displays draws the chosen view on every real screen for a few seconds, with each screen's number and model and a band along each edge that has a neighbour. Esc, a click or 8 seconds closes it. `layout.show` in the API, for the Seam window only.
- **Saved desks** and the border rows on Displays show when a desk was lined up ("Lined up today", "yesterday", "3 days ago", then the date), and dates are in your local time. A desk lined up by an earlier version shows plain "Lined up" until you line it up again. `lined_up_at` in `config.json`.
- A **Help** page in the Seam window, with a topic for each part of Seam and a button to its page. Search finds the topics by their text.
- Seam can turn on Windows' **Ease cursor movement between displays** for you: the Seam window asks once while it's off, and the Displays alert has **Turn it on**. Seam never turns it off. `cursor_easing.set` in the API, and `windows_cursor_easing` in the state.
- **Set as default** on a workspace's "..." menu: when no workspace is remembered, it's the one in use when Seam starts. `workspace.set_default` in the API, and `default` in `workspaces.list`.
- A screen reader now reads the Seam window's sidebar rows, switches, choices, pause button and "..." buttons by name, such as "More for Desk" and "Remap pointer at borders, switch, on".
